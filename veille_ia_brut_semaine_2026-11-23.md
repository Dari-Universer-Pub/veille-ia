### Alibaba lance Qwen4-Max (API, poids fermés)
- **Catégorie** : Sortie majeure de modèle / Baisse de prix API
- **Date de publication** : 16/11/2026
- **Résumé** : Alibaba Cloud a mis en disponibilité générale internationale Qwen4-Max, son modèle phare le plus avancé, avec une fenêtre de contexte allant jusqu'à 1 million de tokens et des prix d'API revus à la baisse par rapport à la génération précédente. Le modèle reste accessible uniquement via l'API et les applications Qwen/Alibaba Cloud ; Alibaba indique que des versions plus petites de la famille Qwen4 seront publiées en poids ouverts, sans date confirmée à ce stade. Une préversion ("Qwen4-Max-Preview") avait été évoquée le 11/11/2026, en dehors de la fenêtre des 7 jours.
- **Source** : https://technode.com/2026/11/16/alibaba-launches-qwen4-max-with-lower-api-prices-and-a-million-token-context-window/ ; https://alibabacloud.com/en/press-room/alibaba-unveils-qwen4-max ; https://www.constellationr.com/insights/news/alibaba-releases-qwen4-max

### OpenAI lance GPT-6.2 Astra et GPT-6.2 Sol
- **Catégorie** : Sortie majeure de modèle / Baisse de prix API
- **Date de publication** : 17/11/2026
- **Résumé** : OpenAI a déployé simultanément dans ChatGPT (Plus, Pro, Enterprise, Edu), Codex et l'API deux nouveaux modèles : GPT-6.2 Astra (modèle frontière pour les tâches les plus exigeantes) et GPT-6.2 Sol (modèle efficace pour l'usage courant). Les prix API annoncés sont de 8 $/40 $ par million de tokens (entrée/sortie) pour Astra — en baisse par rapport à la génération GPT-6 Astra précédente — et 2 $/10 $ pour Sol. Astra est présenté par OpenAI comme le premier modèle déployé publiquement à franchir le seuil "High" d'auto-amélioration de son Preparedness Framework ; ce lancement fait suite à l'abandon d'une version GPT-6.1 Astra précédemment annoncée.
- **Source** : https://openai.com/index/introducing-gpt-6-2-astra-sol ; https://runtimewire.com/article/runtimewire-confirms-gpt-6-2-astra-and-sol-have-launched ; https://decrypt.co/383488/openai-gpt-6-2-astra-challenges-anthropic-price-but-not-every-benchmark

### Google lance Gemini 4 Neon
- **Catégorie** : Sortie majeure de modèle / Baisse de prix API
- **Date de publication** : 18/11/2026
- **Résumé** : Google (annonce de Koray Kavukcuoglu, SVP Google DeepMind) a lancé Gemini 4 Neon, positionné entre le haut de gamme Gemini 4 Carbon et le modèle rapide/économique Gemini 4 Hydrogen, pour les workflows complexes d'ingénierie logicielle, de connaissance et de science. Le modèle est disponible via l'API Gemini, Google AI Studio, Android Studio et Gemini for Business, avec un déploiement progressif vers les abonnés Google AI Pro/Ultra dans l'app Gemini. Prix annoncé : 3 $/15 $ par million de tokens (entrée/sortie) ; Google revendique un coût par tâche inférieur de 32 % à celui de Carbon en mode de réflexion "high". Les classements tiers (Vals AI, etc.) varient selon la source et sont partiellement auto-déclarés.
- **Source** : https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/ ; https://www.testingcatalog.com/google-launches-gemini-4-neon-on-gemini-antigravity-and-apis/ ; https://9to5google.com/2026/11/18/gemini-4-neon-announcement/
